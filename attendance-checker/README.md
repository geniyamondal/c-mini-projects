# Attendance Eligibility Checker

A simple C program that calculates a student's attendance percentage,
checks exam eligibility (75% rule), and tells how many more classes
are needed to become eligible.

## How to Run
```bash
gcc main.c -o attendance
./attendance
```

## Sample Output
```
Total classes held: 40
Classes attended: 20
Attendance: 50.00%
Status: Not eligible.
Attend 40 more consecutive classes to reach 75%.
```

## Concepts Used
Variables, input/output, if-else, arithmetic operators.
